The custom AP pools classes rather than performing accepted COCO per-class aggregation and lacks the required area semantics. `paired_bootstrap` takes only one prediction set and produces a single-set interval, not a paired target-minus-source contrast. Reuse the accepted COCO/XML and image-resampling implementation with source and target inputs, pooled detections, fixed sample plan and stated size endpoints.
